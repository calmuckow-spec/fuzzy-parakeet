# Генератор IES-файлов — инструкция

Версия 1.2. В программе четыре вкладки:

1. Создание файлов IES
2. Отчёты Excel
3. Габаритная яркость
4. Пересчёт на другую цветность

**Габаритная яркость везде считается одинаково:** максимальная осевая сила света, делённая на площадь светового окна.

---

## Часть 1. Как получить файл .exe

### Самый простой способ — скачать готовую сборку

Ничего собирать не нужно, если сборка уже сделана на GitHub. Откройте
репозиторий на GitHub → вкладка **Actions** → слева выберите
**Build Windows app and installer** → откройте последний успешный запуск
(зелёная галочка) → внизу страницы, в разделе **Artifacts**, лежат два
архива:

| Артефакт | Что внутри | Для чего |
|---|---|---|
| `IES-Generator-Installer-Windows` | `IES Generator Setup.exe` | обычная установка: ярлыки в «Пуске» и на рабочем столе, удаление через «Параметры» |
| `IES-Generator-Portable-Windows` | `IES_Generator.exe` одним файлом | без установки: скопировал на флешку и запустил |

**Установщик** не требует прав администратора и не показывает запрос UAC:
программа ставится в профиль пользователя (по умолчанию
`%LOCALAPPDATA%\Programs\IES Generator`). Папку установки можно выбрать
любую, в том числе с пробелами и русскими буквами. Ярлык на рабочем столе
создаётся по умолчанию — галочку можно снять в окне установки. Удаляется
программа обычным способом: **Параметры → Приложения → Установленные
приложения → IES Generator → Удалить**.

Python, tkinter и openpyxl на компьютере пользователя не нужны ни в одном
из двух вариантов — всё уже внутри.

### Если нужно собрать самому, на своём компьютере

Собрать готовый .exe можно только на компьютере с Windows — сборщик (PyInstaller)
не умеет делать это удалённо или на другой операционной системе. Сама сборка
занимает 2–5 минут и делается один раз, шаг за шагом:

1. Установите Python с сайта **python.org** (версия 3.11 или новее, обычная
   версия для Windows, 64-бит).
   При установке обязательно поставьте галочку **«Add python.exe to PATH»** —
   она в самом низу первого окна установщика. Без неё ничего не заработает.
   Если Python уже стоял раньше — этот шаг можно пропустить.
2. Положите все файлы из папки `ies-generator` в одну папку на компьютере,
   например `C:\IES`. Важно, чтобы `ies_app.py`, `ies_core.py`, `ies_report.py`
   и оба `.bat`-файла лежали в одной и той же папке.
3. Дважды щёлкните по файлу **`Собрать_EXE.bat`**. Откроется чёрное окно —
   не закрывайте его.
   - Если Windows спросит «Разрешить этому приложению вносить изменения» —
     нажмите «Да».
   - Программа сама скачает и установит нужные библиотеки (нужен интернет
     на этом единственном шаге), затем соберёт .exe.
4. Дождитесь надписи **«Готово»** в чёрном окне — обычно 2–5 минут, зависит
   от скорости интернета и компьютера. Нажмите любую клавишу, чтобы закрыть
   окно.
5. Готовая программа лежит в подпапке **`dist\IES_Generator.exe`** — это один
   файл размером примерно 15–25 МБ.

Этот один файл можно скопировать на любой другой компьютер с Windows 10/11 —
Python, pip, tkinter и openpyxl там уже не нужны, всё уже внутри .exe.

**При первом запуске .exe** Windows SmartScreen может показать окно
«Windows защитила ваш компьютер» — это стандартная реакция на программы без
цифровой подписи (её никто не выдавал, платно это стоит денег), а не признак
вируса или ошибки сборки. Нужно нажать **«Подробнее»**, затем
**«Выполнить в любом случае»**. Это нужно один раз на каждом новом компьютере.
Если антивирус ругается сильнее (карантин, блокировка) — соберите вместо
этого портативную версию, см. ниже: она реже вызывает ложные срабатывания.

### Портативная версия (папка вместо одного файла)

Если нужна версия, которую можно просто распаковать из архива и сразу
запустить, без «самораспаковки» при каждом старте и с меньшим риском
срабатывания антивируса — дважды щёлкните **`Собрать_Portable.bat`** вместо
`Собрать_EXE.bat`. Результат — папка **`dist\IES_Generator\`** целиком
(в ней много файлов — так и должно быть, это нормально для такой сборки).
Чтобы передать программу на другой компьютер, заархивируйте (zip) всю эту
папку целиком, а не только .exe внутри неё. На другом компьютере: распаковать
архив полностью и запустить `IES_Generator.exe` внутри распакованной папки.

**Если сборка не пошла.** Программу можно запускать и без сборки в .exe:
установите библиотеку командой `pip install openpyxl` и запускайте файл
`ies_app.py` двойным щелчком (для этого варианта Python на компьютере уже
нужен).

**Если обновляете уже собранную программу.** Замените три файла `.py` на
новые и запустите нужный `.bat` заново.

## Часть 2. Вкладка «Создание файлов IES»

### Шаг 1. Базовый файл

Нажмите **«Обзор…»** и выберите исходный IES-файл. Под полем появится серая панель с разбором: кодировка, число углов, оба значения светового потока, осевая сила света и габаритная яркость, наибольшая сила света с указанием угла, габариты, мощность, содержимое полей `[LUMCAT]`, `[LUMINAIRE]`, `[MANUFAC]`.

Габариты и мощность из базового файла подставятся в поля ввода автоматически.

### Шаг 2. Параметры

Заполните: световой поток (лм), мощность (Вт), длину, ширину и высоту в метрах. Можно вводить как через точку, так и через запятую.

- **«Удалять строку [LUMCAT] целиком»** — по умолчанию выключено, строка остаётся, но пустой.
- **«Порог расхождения потоков, %»** — по умолчанию 1 %. Если два значения потока в базовом файле расходятся меньше, программа не переспрашивает.

### Шаг 3. Названия

Два поля, по одной строке на каждый будущий файл: слева имена файлов (латиницей, без `.ies`), справа названия приборов для поля `[LUMINAIRE]`. Количество строк должно совпадать.

### Шаг 4. Папка и запуск

Укажите папку и нажмите **«Создать файлы IES»**. В журнале по каждому файлу выводится контрольная проверка: программа перечитывает записанный файл и заново считает поток и яркость.

### Что программа делает с файлом

| Параметр | Что происходит |
|---|---|
| Силы света | пересчитываются под заданный поток |
| Коэффициент множителя | приводится к 1.00 |
| Люмены на лампу | записывается заданный поток |
| Габариты | заменяются на введённые, в метрах |
| Мощность | заменяется на введённую |
| `[LUMCAT]` | очищается или удаляется |
| `[LUMINAIRE]` | записывается название (строка создаётся, если её не было) |
| `[MANUFAC]` | ставится `ASTZ`, если там было другое |
| `[TESTLAB]`, `[LAMPCAT]` | не трогаются |
| Коэффициент балласта | не трогается |
| Кодировка | koi8-r |

## Часть 3. Вкладка «Отчёты Excel»

### Отчёт 1 — по созданным файлам

Кнопка активна после создания файлов на первой вкладке.

| Столбец | Откуда берётся |
|---|---|
| Название | название прибора из правого поля |
| Световой поток, лм | заданный поток |
| Мощность, Вт | заданная мощность |
| Световая отдача, лм/Вт | формула: поток / мощность |
| Длина, м · Ширина, м | заданные габариты |
| Макс. осевая сила света, кд | из готового файла |
| **Габаритная яркость, кд/м²** | формула: осевая сила света / (длина × ширина) |

### Отчёт 2 — по папке

Укажите любую папку с файлами IES. Одна строка — один файл.

| Столбец | Откуда берётся |
|---|---|
| Название | имя файла |
| Световой поток, лм | поле «люмены на лампу» |
| Мощность, Вт | из файла |
| Световая отдача, лм/Вт | формула |
| Длина · Ширина · Высота, м | из файла |
| Макс. осевая сила света, кд | из файла |
| **Габаритная яркость, кд/м²** | формула: осевая сила света / (длина × ширина) |
| Поток по кривой силы света, лм | независимая проверка |

Столбцы «Макс. осевая сила света» и «Поток по кривой» добавлены сверх вашего списка. Первый нужен, чтобы яркость считалась формулой, а не готовым числом: поправите размеры в Excel — яркость пересчитается сама. Второй показывает, сходится ли поток в файле с его же кривой. Ненужные столбцы удаляются обычным способом.

## Часть 4. Вкладка «Габаритная яркость»

### Шаг 1. Файлы

**«Выбрать файлы IES…»** — обычное окно выбора, можно отметить сразу несколько файлов мышью с зажатым Ctrl или Shift. Кнопка **«Добавить ещё…»** дописывает файлы к списку, если они лежат в разных папках.

### Шаг 2. Размер светового окна

Введите длину и ширину в метрах. Кнопка **«Подставить размеры из первого файла»** возьмёт их из самого IES.

### Шаг 3. Расчёт

Нажмите **«Рассчитать и выгрузить в Excel»**. Столбцы отчёта: Название светового прибора, Световой поток (лм), Мощность (Вт), Световая отдача (лм/Вт), Макс. осевая сила света (кд), Габаритная яркость (кд/м²).

Название берётся из `[LUMINAIRE]`; если поле пустое — из `[LUMCAT]`; если и оно пустое — имя файла.

Размер светового окна записан в жёлтые ячейки наверху листа. Если поменять их прямо в Excel, вся колонка яркости пересчитается — можно быстро прикинуть несколько вариантов окна без повторного запуска программы.

## Часть 5. Вкладка «Пересчёт на другую цветность»

### Шаг 1. Папка

Укажите папку с исходными файлами. Обрабатываются все файлы `.ies` в ней.

### Шаг 2. Параметры

- **Коэффициент для светового потока** — на него умножается поток. Например, при переходе с 840 на 930 поток обычно падает, и коэффициент будет около 0.88.
- **Новый код цветности** — ровно три цифры: 930, 940, 957 и так далее.
- **Имя новой папки** — она будет создана внутри папки с исходниками.

### Шаг 3. Две галочки

**«Пересчитывать силы света вместе с потоком»** — включена по умолчанию, и менять это без причины не стоит. Расчётные программы вроде DIALux берут поток не из поля «люмены на лампу», а из самой кривой силы света. Если умножить только поле, файл станет противоречивым: в паспорте одно число, в расчёте другое.

**«Менять код цветности также в поле [LUMCAT]»** — по умолчанию выключена. Она нужна только для файлов, где `[LUMINAIRE]` уже заполнен, а код продублирован ещё и в `[LUMCAT]`.

### Что программа делает с каждым файлом

1. Поле «люмены на лампу» умножается на коэффициент.
2. Кривая силы света умножается на тот же коэффициент (если галочка включена).
3. Множитель приводится к 1.00.
4. Мощность не меняется — при смене цветности она остаётся прежней, меняется только отдача.
5. **Если поле `[LUMINAIRE]` пустое или отсутствует, название переносится в него из `[LUMCAT]`, а `[LUMCAT]` очищается.** Дальше программа работает с `[LUMINAIRE]`.
6. В конце значения `[LUMINAIRE]` трёхзначный код заменяется на новый.
7. В конце имени файла трёхзначный код заменяется на тот же новый.
8. Файл сохраняется в koi8-r. Если исходник был в другой кодировке, в журнале появится строка об этом.

### Защита от потери файлов

Перед началом работы программа проверяет, не получат ли разные файлы одинаковое имя. Это бывает, когда в одной папке лежат файлы с разными кодами: `..._840.IES` и `..._940.IES` при пересчёте на 930 оба превратятся в `..._930.IES`, и второй затрёт первый.

В таком случае программа ничего не делает, а показывает список конфликтов. Разложите файлы по папкам с одинаковым кодом и пересчитайте каждую отдельно.

Если трёхзначного кода в конце нет — ни в названии, ни в имени файла — программа напишет предупреждение и оставит прежнее значение. Сам файл при этом всё равно пересчитается.

## Что было проверено

На ваших трёх файлах:

| Файл | Поток, лм | Осевая сила света, кд | Площадь окна, м² | Габаритная яркость, кд/м² |
|---|---|---|---|---|
| DPO12-30-003 840 | 3925 | 1329.1 | 0.3540 | 3754 |
| DPO12-38-003 840 | 4656 | 1576.4 | 0.3540 | 4453 |
| DPO12-38-003 940 | 3799.9 | 1286.6 | 0.3511 | 3665 |

Отдельно проверено:

1. Пересчёт потока — отклонение 0.0000 % при контрольном перечитывании.
2. Интегратор потока на источнике с известным ответом — совпал с теорией.
3. Площадь круглого прибора: отрицательные габариты трактуются как диаметр.
4. Замена трёхзначного кода: в именах с подчёркиваниями, с пробелами, с хвостовым пробелом, и в названиях, где кода нет.
5. Перенос названия из `[LUMCAT]` в пустое `[LUMINAIRE]` на всех трёх ваших файлах.
6. Файл с уже заполненным `[LUMINAIRE]` — перенос не срабатывает, `[LUMCAT]` остаётся нетронутым.
7. Обнаружение совпадающих имён при смешанной папке 840 + 940.
8. Пересчёт на цветность: и поле люмен, и кривая умножаются на коэффициент, множитель становится 1.00, мощность и `[LAMPCAT]` сохраняются.
9. Все формулы в трёх отчётах Excel — пересчитываются без ошибок.

Замечание по файлу `DPO12-38-003_Universal_Soft_940`: наибольшая сила света в нём приходится не на 0°, а на 1° — 1286.8 кд против 1286.6 кд на оси. В расчёт яркости берётся осевое значение, а если разница превысит 1 %, программа напишет об этом в журнале и укажет угол.

## Состав папки

| Файл | Назначение |
|---|---|
| `ies_app.py` | интерфейс программы |
| `ies_core.py` | чтение, пересчёт и запись IES |
| `ies_report.py` | выгрузка в Excel |
| `Собрать_EXE.bat` | сборка одного файла `dist\IES_Generator.exe` |
| `Собрать_Portable.bat` | сборка портативной папки `dist\IES_Generator\` |
| `requirements.txt` | список библиотек для `pip install -r requirements.txt` |
| `Инструкция.md` | этот файл |

Все три файла `.py` и оба `.bat`-файла должны лежать в одной папке.
