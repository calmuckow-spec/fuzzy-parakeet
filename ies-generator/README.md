# IES Generator — Windows build

This folder holds the Python source for **IES Generator**, a Tkinter desktop
tool for regenerating IESNA LM-63 photometric (`.ies`) files and producing
Excel reports. The full user manual (in Russian) is in `Инструкция.md`.

## Getting a ready-to-run Windows build (no Python required)

A GitHub Actions workflow at `.github/workflows/build-windows.yml` builds
everything on a real `windows-latest` runner — PyInstaller can't
cross-compile, so this is the way to get a genuine Windows build without
owning a Windows machine yourself.

One run produces **two** downloads:

| Artifact | What's inside | When to use it |
|---|---|---|
| `IES-Generator-Installer-Windows` | `IES Generator Setup.exe` | Normal installation: Start Menu and Desktop shortcuts, uninstaller |
| `IES-Generator-Portable-Windows` | `IES_Generator.exe` (single file) | No installation at all — copy it to a USB stick and run |

### 1. Start the build

- Open this repository on GitHub and go to the **Actions** tab.
- Select **Build Windows app and installer** in the workflow list on the left.
- Click **Run workflow**, pick the branch to build, and confirm.
- (It also runs automatically whenever a commit changes anything under
  `ies-generator/` or `installer/`.)

### 2. Download the result

- Wait for the run to finish — typically 4–6 minutes.
- Open the completed run and scroll to the **Artifacts** section at the
  bottom of the run summary page.
- Download **`IES-Generator-Installer-Windows`** (the installer) or
  **`IES-Generator-Portable-Windows`** (the portable single file). GitHub
  always delivers artifacts as a `.zip`, so unzip it first.

### 3a. Install it on Windows 10/11

- Unzip and run **`IES Generator Setup.exe`**.
- The installer is **per-user**: it needs no administrator rights and does
  not show a UAC prompt. It installs into
  `%LOCALAPPDATA%\Programs\IES Generator` by default, and you can pick any
  other folder — paths with spaces and Cyrillic characters work fine.
- It creates a Start Menu group (application + manual) and, unless you
  untick the option, a Desktop shortcut.
- To remove it later: **Settings → Apps → Installed apps → IES Generator →
  Uninstall**.

### 3b. Or just run the portable build

- Unzip `IES_Generator.exe` anywhere (Desktop, `C:\IES`, a USB stick) and
  double-click it. Nothing gets installed and nothing is written to the
  registry.

Either way, Python, pip, tkinter and openpyxl are **not** needed on the
target computer — everything is bundled.

### About the SmartScreen warning

On the first launch of either file, Windows SmartScreen may show
**"Windows protected your PC"**, because the build isn't code-signed (a
signing certificate costs money and isn't set up for this project). Click
**More info** → **Run anyway**. That's expected for any unsigned
executable, not a sign of a broken build.

## Application icon

`installer/icon.ico` is currently a **placeholder** generated by
`installer/make_placeholder_icon.py` (a simple luminaire glyph). It is used
for the `.exe`, the installer and both shortcuts. To use real branding,
replace `installer/icon.ico` with your own `.ico` file — the build picks it
up automatically and the generator script never overwrites an existing file.

## Version number

The version lives in exactly one place: `VERSION` in `ies-generator/ies_app.py`
(currently `1.2` → normalised to `1.2.0`). `installer/make_version_file.py`
feeds it to both the `.exe` version resource and the installer, so bumping
that one line is enough.

## Building locally instead

To build on your own Windows machine by double-clicking a `.bat` file
instead of using GitHub Actions, see the "Как получить файл .exe" section of
`Инструкция.md`. Note that the local `.bat` scripts build the application
only — the installer is produced by the GitHub Actions workflow (or by
running Inno Setup against `installer/IES-Generator.iss` yourself).
